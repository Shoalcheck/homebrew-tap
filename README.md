# shoalcheck/tap

```
brew install shoalcheck/tap/shoalcheck
```

Installs the Shoalcheck command line on macOS and Linux: read-only Kubernetes preflight and audit, from your
laptop. `brew upgrade shoalcheck` follows each stable release.

The desktop app, the kubectl plugin and the MCP server are on the releases page:
[shoalcheck/shoalcheck](https://github.com/shoalcheck/shoalcheck/releases). Website: https://shoalcheck.com
