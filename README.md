# shoalcheck/tap

```
brew install shoalcheck/tap/shoalcheck
```

**No formula is published yet.** The release job writes it with the first stable Shoalcheck version (every
release so far is a prerelease), and until then the command above answers "No available formula". Download the
command line from the releases page meanwhile; `shoalcheck upgrade` keeps it current. The formula will install the
command line on macOS and Linux. Releases and the desktop app: [shoalcheck/shoalcheck](https://github.com/shoalcheck/shoalcheck).
